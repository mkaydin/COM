### Raspberry Pi computer hardware - Raspberry Pi Documentation
Raspberry Pi 2 Model B revisions 1.1 and 1.2 reached End‑of‑Life on 16 October 2025 due to the discontinuation of the core SoC. Raspberry Pi 2 Model B 1.3 retains the same mechanical footprint and a BCM2837B0 processor. Compute Module 3 and 3 Lite also reached End‑of‑Life on 16 October 2025 for the same reason. The closest alternative for Compute Module 3 is Raspberry Pi Compute Module 3+ which offers the same footprint, improved thermal design, and a BCM2837B0 processor.
